= Obtenga información sobre las preferencias de facturación para licencias y suscripciones.
:hardbreaks:
:allow-uri-read: 
:nofooter:

:imagesdir: ./media/


[role="lead"]
Las preferencias de facturación le permiten determinar cómo gestionar los pagos y el comportamiento de renovación de sus licencias y suscripciones activas. Puede aplicar estas preferencias de forma global, de modo que afecten a todas las relaciones de facturación, o a nivel de suscripción individual cuando un contrato específico requiera su propia configuración.

* *Las suscripciones a Marketplace* corresponden a contratos de marketplace en la nube (AWS, Azure o Google Cloud) donde los cargos por uso se hacen a través de una cuenta del proveedor de la nube
* Las *licencias directas* representan licencias compradas directamente a NetApp, administradas en la NetApp Console a través de claves de licencia, destinatarios de facturas y opciones de renovación.


Puedes configurar cómo tu organización asigna y paga los servicios según tu modelo de adquisición.



[[permissions]]
== Permisos

La gestión de licencias y suscripciones dentro de la NetApp Console se controla mediante roles de usuario. Estos roles proporcionan distintos niveles de acceso, habilitando o restringiendo acciones específicas que los usuarios pueden realizar para esta función.

[cols="2,5"]
|===
| Role | Descripción 


| *Administración*  a| 
Los usuarios con este rol tienen control total sobre las licencias y las suscripciones. Los usuarios administradores pueden:

* Ver todas las licencias y suscripciones.
* Agregar nuevas licencias.
* Asociar las suscripciones con las cuentas.
* Modificar los detalles de la licencia existente.
* Eliminar licencias o desvincular suscripciones.




| *Espectador*  a| 
Los usuarios con este rol tienen acceso de solo lectura. Los usuarios del visor pueden:

* Ver todas las licencias y suscripciones.


|===


[[billing-preferences]]
== Preferencias de facturación

Las preferencias de facturación garantizan que los cargos por uso y las renovaciones se apliquen correctamente.  Una configuración adecuada reduce las disputas de facturación y facilita la gestión de modelos de licencias híbridos que combinan la capacidad propiedad de NetApp con la capacidad adquirida en el marketplace.

Por ejemplo, las preferencias de facturación global pueden unificar la lista de contactos de facturación para que todos los servicios compartan un único administrador de facturación. También puedes usar etiquetas de centros de coste para alinear el uso entre departamentos o regiones, y activar la renovación automática para evitar interrupciones del servicio. Las nuevas implementaciones de Cloud Volumes ONTAP heredan automáticamente el modo de facturación que defines aquí, lo que mantiene coherente el modelo de pago por uso de tu organización a medida que se añaden nuevos sistemas.

Las preferencias de facturación se configuran en la sección * Licenses and subscriptions* de la NetApp Console.

Desde ahí, puedes:

* Configure las preferencias de facturación para su organización.
* Activar la asignación avanzada de instancias de Cloud Volumes ONTAP a suscripciones de marketplace
* Edita o actualiza los detalles de tu suscripción al mercado.




[[flexible-billing-for-cloud-volumes-ontap-and-data-services-in-aws]]
== Facturación flexible para Cloud Volumes ONTAP y servicios de datos en AWS

En AWS, la capacidad de Cloud Volumes ONTAP y los servicios de datos de NetApp pueden facturarse a través de diferentes suscripciones de AWS Marketplace. Para obtener detalles sobre los cambios y recomendaciones del AWS Enterprise Discount Program (EDP), consulta el link:https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/whats-new.html#flexible-billing-for-cloud-volumes-ontap-and-data-services-in-aws["Notas de la versión de Cloud Volumes ONTAP"].

Si en tu cuenta de AWS dispones tanto de una suscripción independiente a Cloud Volumes ONTAP como de una suscripción a NetApp Intelligent Services (NIS), puedes usar *Billing preferences* para elegir qué suscripción se usa para la facturación de la capacidad de Cloud Volumes ONTAP.


NOTE: El comportamiento de la facturación depende de si ya tienes sistemas Cloud Volumes ONTAP en funcionamiento y facturados a través de NIS, o si estás implementando nuevos sistemas después de añadir la suscripción independiente de Cloud Volumes ONTAP. Para los sistemas existentes, añadir la suscripción independiente no cambia la facturación a menos que actualices las *Billing preferences*. Para las nuevas implementaciones creadas después de que la suscripción independiente esté disponible, la suscripción independiente se usa por defecto para la facturación de la capacidad de Cloud Volumes ONTAP (Essentials/Freemium), a menos que lo cambies en las *Billing preferences*.

* Suscripción independiente a Cloud Volumes ONTAP (recomendada): capacidad de Cloud Volumes ONTAP (Essentials/Freemium)
* NetApp Intelligent Services (NIS) subscription: servicios de datos de NetApp (y Cloud Volumes ONTAP Professional)


La suscripción independiente a Cloud Volumes ONTAP solo admite los paquetes Essentials y Freemium basados en capacidad. El paquete Professional no es compatible y se sigue facturando a través de NIS. Si solo tienes asociada la suscripción independiente, puedes implementar Cloud Volumes ONTAP usando Essentials, pero configurar Backup and Recovery requiere una suscripción diferente.



[[where-to-configure-it]]
=== Dónde configurarlo

Asocias las suscripciones de AWS marketplace en *Administración > Licenses and subscriptions > Marketplace subscriptions*, y eliges la suscripción de marketplace que se usará para la facturación de capacidad de Cloud Volumes ONTAP en *Administración > Licenses and subscriptions > Billing preferences*. Puedes comprobar los detalles de facturación usando los informes de uso de Cloud Volumes ONTAP.


NOTE: No se duplica la medición cuando usas varios tipos de suscripción o migras entre listados.



[[fields]]
== Campos

Los campos de facturación almacenan metadatos sobre cómo se factura cada licencia o suscripción.  Describen a quién se le factura, cómo se realizan las renovaciones y a qué cuenta o centro de costos pertenece cada servicio.



[[marketplace-fields]]
=== Campos del mercado

Los campos de marketplace describen los contratos que se originan en un proveedor de nube como AWS, Azure o Google Cloud. Estos campos definen cómo NetApp Console conecta tus suscripciones con la información de facturación almacenada en el marketplace del proveedor. También controlan cómo se gestionan las renovaciones, las asignaciones regionales y las cuentas de facturación.

* *Marketplace provider* — identifica la plataforma en la nube donde se gestiona la facturación. El proveedor determina las funciones compatibles, los tipos de contrato y las normas de renovación. Por ejemplo, las suscripciones de AWS Marketplace utilizan la facturación basada en la cuenta, mientras que Azure puede admitir tanto el modelo basado en la cuenta como el basado en el inquilino.
* *ID de cuenta de facturación o suscripción* — Especifica el identificador único de la cuenta utilizada para procesar los cargos.  Esto garantiza que los datos de uso se facturen al perfil de facturación en la nube correcto.
* *Plazo del contrato* — Define la duración de la suscripción y las opciones de renovación.




[[direct-license-fields]]
=== Campos de licencia directa

Los campos de licencia directa se aplican a los contratos gestionados por NetApp adquiridos directamente, en lugar de a través de un mercado en la nube.  Definen cómo NetApp le factura, a dónde se envían los cargos y qué entidad legal aparece en la factura.  Estos campos son fundamentales para las organizaciones que utilizan órdenes de compra o facturación corporativa centralizada.



[[keystone-fields]]
=== Campos Keystone

Los campos de Keystone se aplican al uso que se encuentra dentro de un acuerdo de suscripción de NetApp Keystone .  Te permiten conectar el uso del servicio medido a tu perfil de facturación de Keystone , alineando los datos de suscripción con otros modelos de licencia basados ​​en capacidad.

* *ID del acuerdo* — Un identificador único para el contrato de Keystone .  Vincula el registro de facturación en la NetApp Console con su acuerdo de Keystone y permite la sincronización de los informes de uso.
* *Alcance del servicio* — Enumera los servicios o grupos de capacidad que se incluyen en el acuerdo Keystone .  Este campo aclara qué cargas de trabajo o despliegues están incluidos en el contrato y garantiza que solo se facturen a través de Keystone los recursos que cumplan los requisitos.




[[billing-options-and-definitions]]
== Opciones y definiciones de facturación

Las opciones de facturación definen cómo NetApp Console prioriza y aplica los cargos por uso cuando se conectan varias fuentes de facturación.  Controlan qué cuenta se carga primero y cómo cambia la facturación entre las licencias de NetApp y las suscripciones del marketplace cuando se alcanzan los límites de capacidad.



[[terms-and-options]]
=== Términos y opciones

Puedes elegir entre distintos modos de facturación según la estrategia de aprovisionamiento de tu organización:

* *Primero las licencias de NetApp * — Prioriza la facturación a través de las licencias activas de NetApp .  Cuando se agota la capacidad de estas licencias, el uso se transfiere automáticamente a la suscripción del mercado vinculado.
* *Solo suscripciones a Marketplace* — Toda la facturación se realiza a través de contratos de Marketplace, sin utilizar las licencias de NetApp .  Esto es común en organizaciones que estandarizan las adquisiciones mediante la facturación de proveedores de servicios en la nube.
* *PAYGO (Pago por uso)* — Se facturan únicamente los consumos reales.
* *Contrato anual* — Establece un plazo de suscripción definido.
* *Renovación automática* — Permite la continuación automática de las licencias o contratos del mercado cuando caducan.  Deshabilitar esta opción requiere una renovación manual para evitar la interrupción del servicio.
* *Configuración personalizada de Cloud Volumes ONTAP* — permite asignar varias suscripciones de marketplace a un proveedor de nube. Esto puede ser útil cuando diferentes unidades de negocio o proyectos requieren cuentas de facturación distintas dentro del mismo entorno de nube.




[[typical-configuration-paths]]
=== Rutas de configuración típicas

Los siguientes ejemplos ilustran cómo las diferentes configuraciones de facturación se adaptan a los casos comunes:

|===
| Guión | Opción de facturación recomendada 


| Su organización adquirió capacidad de NetApp directamente. | *Primero, licencias de NetApp * 


| Todo el uso se factura mediante contratos de mercado. | *Solo suscripciones al Marketplace* 


| Facturas varios proyectos a un solo proveedor de nube. | *Habilitar configuración personalizada de CVO* 


| Desea volver a una configuración de facturación simple de una sola fuente. | *Deshabilitar la configuración personalizada de CVO* 
|===
Por ejemplo, considera una organización que combina tanto licencias directas de NetApp como suscripciones de marketplace. Una configuración típica establecería *NetApp licenses first* como el modo de facturación predeterminado para usar la capacidad prepagada antes de la facturación de marketplace. Luego, en *Custom CVO configuration*, a cada proveedor de cloud (AWS, Azure, Google Cloud) se le asignaría su ID de suscripción correspondiente.

Después de guardar esta configuración, los administradores pueden revisar las asignaciones en * Licenses and subscriptions* para verificar que cada servicio apunte a la cuenta correcta.  Para una validación adicional, pueden comparar los datos de uso en la NetApp Console con los paneles de facturación en la nube y ajustar las etiquetas de los centros de costos o los contactos según sea necesario para mantener la coherencia de los informes.
